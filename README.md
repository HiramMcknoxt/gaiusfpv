# GaiusFPV

Lyrical freestyle FPV from Cabot, Arkansas — one song, one take, takeoff to landing.

Live site: https://hirammcknoxt.github.io/gaiusfpv/

## What's here

- **Live video feed** — the "Latest uploads" player pulls GaiusFPV's newest YouTube uploads automatically (uploads playlist `UUoRtX16UjIFiYMpEcItMwIA`, channel `UCoRtX16UjIFiYMpEcItMwIA` / @GaiusFPV).
- **Recent + most-watched flights** — rendered from `data.json`, built from the channel catalogue (Nov 7, 2026 snapshot; view counts were true then).
- **Song requests** — embeds the live Google Form "GaiusFPV — Song Requests" and the Spotify "GaiusFPV Request Playlist" (`7KVkj6L62lwrg3XQ7u8oYh`). Accepted requests are added to that playlist; songs already posted as flights are skipped.
- **Already flown?** — searchable list of 225 catalogued song flights from `data.json`, so fans can check before requesting.

## Updating the video lists

Re-pull the channel catalogue and regenerate `data.json` (latest FPV-filtered videos, most-watched FPV, flown titles), then push. The live uploads player needs no updating.
